# 👨‍💻 Bilal Yılmaz - Personal Portfolio

This project contains the source code for my personal portfolio website, showcasing my work and skills.

🔗 **Live Site:** [https://imbilalyilmaz.github.io](https://imbilalyilmaz.github.io)

## 🛠 Technologies Used

- **Framework:** Next.js 14 (Static Export)
- **Language:** JavaScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Deployment:** GitHub Actions & GitHub Pages

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
